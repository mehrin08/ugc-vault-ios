# UGC Vault 1.1 plan

Version 1.0 (build 6) was submitted for App Store review on 2026-10-02. Nothing below
should go live until 1.0 is approved.

## Goals
1. Subscriptions ($4.99/month + yearly, 3-day free trial). The code already exists behind `SUBSCRIPTIONS_ON`.
2. Own domain + Cloudflare Pages hosting, so the app no longer depends on Netlify's
   free credits (the free plan pauses the site when its 300 monthly credits run out).

## Now, while 1.0 is in review (paperwork only)
- [ ] App Store Connect → Business: accept the **Paid Apps** agreement
- [ ] Add bank account
- [ ] Tax forms (W-8BEN + Canadian tax info)
- [ ] Apply for the **App Store Small Business Program** (15% commission instead of 30%)
- [ ] Buy a domain (e.g. `ugcvault.app`, ~$15/yr). Buying it through Cloudflare Registrar keeps it all in one place
- [ ] Create a free Cloudflare account

## Hosting move (after 1.0 is approved)
1. Create a Cloudflare Pages project and upload `web/` (index.html, native.js, music1/2.mp3,
   privacy.html, support.html). Deploy with `npx wrangler pages deploy web --project-name ugc-vault`.
2. Connect the custom domain (e.g. `app.ugcvault.app`) to the Pages project.
3. Point everything at the domain:
   - `capacitor.config.ts` → `server.url`
   - `PRIVACY_URL` in `web/index.html`
   - App Store Connect: Privacy Policy URL, Support URL, Marketing URL
   - Supabase → Auth → URL configuration: add the new domain to Site URL / redirect URLs
4. **Keep the Netlify site running and in sync.** Phones still on 1.0 load the app from
   `thriving-macaron-6a97f3.netlify.app` until they update, and a redirect there would open
   Safari instead of the app. Once almost everyone is on 1.1+, Netlify traffic drops to near zero.
5. Deploy to both hosts with one script until then.

## Subscriptions (after 1.0 is approved)
1. App Store Connect → Subscriptions: create a group "UGC Vault Pro" with
   `com.rims.ugcvault.monthly` ($4.99) and `com.rims.ugcvault.yearly`, each with a 3-day free trial.
2. **Gate the flag on the app version, not just `SUBSCRIPTIONS_ON`.** The web code is live for
   every installed version, so flipping the flag alone would show the paywall inside 1.0, a
   build Apple reviewed as free. Only show it when the native app reports version ≥ 1.1.
3. Decide what happens to people who signed up during the free 1.0 period (suggestion:
   give them a free month or permanent free access as early supporters).
4. App Store Connect → App Privacy: add **Purchases** (App Functionality, linked, no tracking).
   Do **not** add Payment Info, because Apple handles cards.
5. App Store Connect → App Information: switch DSA status to **trader** (needs business
   contact details shown publicly in the EU).
6. Review notes: explain the trial and paywall, and make sure the demo account
   (ugcrims+review@gmail.com) can reach the paywall. Attach the subscriptions to the 1.1 version.
7. Bump version to 1.1 / next build, archive, upload, submit.

## Backend costs once people pay
| Item | Cost |
|---|---|
| Supabase Pro (daily backups, never pauses) | $25/mo, upgrade when subscriptions launch |
| Cloudflare Pages | free (unlimited bandwidth) |
| Domain | ~$15/yr |
| Apple Developer Program | $99/yr |

At $4.99/month, about $4.24 per subscriber after Apple's 15%, so break-even is about 7–9 subscribers.
